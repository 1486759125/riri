# 日日 · 每日任务清单

一个无需安装依赖的每日任务网站，直接打开 `index.html` 即可使用。

## 已实现

- 多个清单的新建、切换、重命名和删除
- 每个清单右侧提供管理按钮，侧边栏另有明确的“管理当前清单”入口
- 清单较多时列表区域独立滚动，不会与管理按钮或左下角寄语重叠
- 左下角寄语支持自定义内容，并可随时恢复系统默认
- 完整月历日期选择界面，可按月翻页并查看每天的记录数量
- 任务优先级使用颜色编码的下拉菜单，不再需要循环点选
- “我的清单”区域可拖动调整高度、收起或展开，并会记住设置
- 柔和界面音效开关，不同时间视图、清单和筛选标签使用不同音高
- 新增、勾选完成、标记未完成、修改优先级和删除任务提供独立操作反馈
- 樱花养成系统：完成不同任务会让树逐步长大，连续完成的日子会生成花瓣
- 每天前 3 项新计划提供少量成长值；遗漏一天扣除 10 个花瓣
- App 启动时优先展示全屏樱花树，可在“小树状况”和“设定今日任务”之间切换
- 小树状况说明使用柔和天空批注，进度与成长数据收纳在独立浮层中
- 樱花、银杏、枫树为初始树种；完成连续打卡或使用金币可解锁三个神秘树种
- 每日首次完成任务可获得金币，完成不同任务也会增加金币
- 时间视图：在今天、历史记录和未来计划之间切换
- 历史记录按日期汇总所有清单，并以只读方式回看
- 未来计划支持选择日期并为不同清单提前安排任务
- 手动添加任务，支持红 / 橙 / 绿 / 灰四档优先级
- 使用勾号标记完成、叉号标记未完成
- 当前清单完成进度实时更新，并自动保存到浏览器本地
- 进度 100% 显示笑脸，60%–99% 显示平静脸，低于 60% 显示生气脸
- 从 TXT、Markdown、CSV、JSON 文件导入任务，支持拖放与重复项过滤
- 导出当前清单，删除任务后可撤销
- 桌面端与移动端适配

旧版本中已经录入的任务会自动归入升级当天，不会因升级而丢失。

## 文件导入格式

最简单的方式是一行一个任务：

```text
整理项目周报 | 紧急
阅读 30 分钟 | 重要
给植物浇水 | 日常
整理下周照片 | 稍后
```

也支持 `!!! 任务`、`!! 任务`、`! 任务`，或 `[紧急] 任务` 这类写法。CSV 的第一列为任务名称，第二列可填写优先级。

网站数据保存在浏览器 `localStorage` 中。清除浏览器站点数据会同时清除清单。

## 安装为 App

页面已支持 PWA 安装和离线缓存。将 `日日清单-APP.zip` 或当前目录中的全部文件部署到 HTTPS 静态网站后，可以在手机浏览器中安装到桌面。详细步骤见 `APP-INSTALL.md`。

直接打开本地 `index.html` 可以正常使用网站功能，但浏览器不允许通过 `file://` 地址安装 PWA。
